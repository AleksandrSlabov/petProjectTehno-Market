🔄 Процесс обновления сайта на GitHub Pages
Вносишь изменения в код (в своей основной ветке, например main).

Коммитишь и пушишь их в репозиторий:

bash
git add .
git commit -m "Описание изменений"
git push origin main
Запускаешь деплой, который соберёт проект и обновит ветку gh-pages:

bash
npm run deploy
После этого ветка gh-pages автоматически обновится, и через пару минут изменения появятся на твоём сайте.

📌 Важные моменты
Никогда не редактируй ветку gh-pages вручную – она полностью управляется командой npm run deploy. Любые ручные правки будут перезаписаны при следующем деплое.

Убедись, что в package.json у тебя правильно прописаны скрипты predeploy и deploy (как мы обсуждали ранее).

После git push в main не забудь выполнить npm run deploy, иначе сайт не обновится.

Если вдруг после npm run deploy изменения не появились – проверь, что в настройках GitHub Pages (Settings → Pages) выбрана ветка gh-pages и папка /root. Обычно это делается один раз при первом деплое.
